Zvec AI 构建轻量、可嵌入的搜索组件，让搜索运行在数据所在的位置。将向量检索、全文检索和混合检索直接嵌入应用、设备、本地工具和 Agent 工作流，无需单独运维数据库服务。

## 🚀 从这里开始

| [Zvec](https://github.com/alibaba/zvec) | [zvec-grep](https://github.com/zvec-ai/zvec-grep) | [Zvec Studio](https://github.com/zvec-ai/zvec-studio) |
| --- | --- | --- |
| **将搜索嵌入应用** | **搜索本地工作区** | **可视化探索和调试** |
| 轻量、极速的进程内数据库，支持向量检索、全文检索和混合检索。 | 面向用户与 AI Agent 的本地优先统一搜索入口，支持精确文本、正则、BM25 和向量检索。 | 无需编写代码，即可浏览数据、管理 Schema 并测试 Zvec 查询的可视化工具。 |
| `pip install zvec`<br>`npm install @zvec/zvec` | `npm install -g @zvec/zvec-grep` | `pip install zvec-studio` |
| [快速开始](https://zvec.org/zh/docs/db/quickstart/) · [性能报告](https://zvec.org/zh/docs/db/benchmarks/) | [动手体验](https://github.com/zvec-ai/zvec-grep/blob/main/README_CN.md#try-it-yourself) · [文档](https://github.com/zvec-ai/zvec-grep/tree/main/docs) | [快速开始](https://github.com/zvec-ai/zvec-studio#-quick-start) · [发布版本](https://github.com/zvec-ai/zvec-studio/releases) |
